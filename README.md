# JOLT

**Stream light. Play loud.** A native Windows music player with real online streaming, local favorites and playlists, Windows media controls, and optional Discord Rich Presence.

[Download the Windows x64 installer](https://github.com/subliminalsidkthemeaning/JOLT/releases/latest/download/JOLT-Setup-x64.exe) · [Portable ZIP and release notes](https://github.com/subliminalsidkthemeaning/JOLT/releases/latest)

The installer is per-user and includes its required Microsoft runtime files. The builds are unsigned. Portable users should extract the entire folder and keep its DLLs together. Streaming requires internet access; catalog availability depends on the service, region and account rights.

Discord presence is optional and off by default. Enable it in Settings → Discord while the Discord desktop client is running. It uses local RPC with a public Application ID, never a bot token, client secret, OAuth sign-in or hosted server. The Download JOLT activity button appears only after its public installer link is verified. Discord may hide your own activity buttons from you; another viewer can see them.

This public repository hosts release files, documentation and required notices. JOLT's source code is not published here.
